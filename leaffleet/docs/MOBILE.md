# Мобільна верстка — 16.10.2026

Існуючий стиль і поведінку сервера збережено. Мобільна композиція застосовується до 1023 CSS px, з окремими правилами для вузьких екранів і горизонтального положення.

- viewport-fit=cover, безпечні відступи iPhone та запас під нижнім меню.
- Заголовок і керування мають окремі рядки. Невидима кнопка демо не зміщує кнопки теми й оновлення.
- SOC, автомобіль і час вимірювання розташовані в потоці документа. Ширина ілюстрації обмежена карткою.
- Швидкі дії, показники та значення даних використовують колонки minmax(0,1fr) й допускають перенесення довгого тексту.
- Історія має вертикальні картки; заряд/відстань та енергія займають повну ширину.
- Поля мають шрифт 16 px, цифрові режими клавіатури та нормальні відступи. Нижнє меню приховується під час редагування поля.
- Кнопки керування мають області натискання від 44 px; враховано короткий горизонтальний екран.
- Демопанель обмежена динамічною висотою екрана; керування залишається липким під час прокрутки.
- CSS-посилання містить версію, щоб телефон отримав оновлений файл стилів.

Перевірено синтаксис CSS через PostCSS і Lightning CSS, структуру HTML та чинну модель контролера. Перевірка реального рендерингу Safari/Chrome недоступна: control-browser у середовищі не підключено; альтернативний браузерний шлях не використовувався. Значення ширин у CSS не є доказом перевірки на фізичних пристроях.
