# Подключение LeafFleet к Nissan Leaf 2014

Цель: пассивно читать EV-CAN. Аппаратный Silent дополняет `TWAI_MODE_LISTEN_ONLY`. Для первых испытаний ESP питается отдельным USB; контакт питания OBD оставь свободным.

## Компоненты

| Компонент | Требование |
|---|---|
| ESP32-S3 DevKit | GPIO4/5 доступны, Flash с разделом файловой системы >=1 МБ |
| Adafruit CAN Pal #5708 | Трансивер TJA1051T/3, отдельный SLNT, питание 3,3 В |
| OBD-II штекер / разветвитель | Выводы нужных контактов проверены прозвонкой |
| CAN-провод | Короткая витая пара, защищённые соединения |
| Предохранитель | 1 А для выбранной цепи; номинал согласовать с проводкой и током устройств |
| Автомобильный DC-DC 12→5 В | Документированная защита от импульсов, переполюсовки, КЗ |
| Отсечка низкого напряжения | Аппаратная, порог подобран под 12-вольтовый АКБ |
| Корпус, крепление, изоляция | Защита от касаний, нагрева и вибрации |
| Android с интернетом | Hotspot 2,4 ГГц, стабильное питание |
| GNSS, необязательно | UART 3,3 В, например совместимый модуль u-blox; питание по его спецификации |

## ESP → CAN Pal

| От ESP32-S3 | На CAN Pal | Назначение |
|---|---|---|
| 3V3 | Vcc | Питание логики модуля |
| GND | GND | Общая земля |
| GPIO4 | TX | Выход TWAI; прошивка работает listen-only |
| GPIO5 | RX | Вход TWAI |
| **3V3 отдельным постоянным соединением** | **SLNT** | Аппаратное отключение передачи |
| — | Termination **OFF** | Штатная шина уже имеет терминаторы |

Проверяй названия на конкретном модуле. GPIO22 у ESP32-S3 отсутствует. Модуль другого типа может требовать иной схемы питания и управления Silent.

## CAN Pal → диагностический разъём

Для AZE0 широко применяется следующая распиновка; её нужно подтвердить по сервисной схеме своей машины и маркировке конкретного штекера.

| OBD-II | Назначение | Подключение |
|---|---|---|
| 13 | EV-CAN High | CANH |
| 12 | EV-CAN Low | CANL |
| 4 / 5 | Кузовная / сигнальная земля | Земля по подтверждённой сервисной схеме |
| 16 | Постоянные +12 В | Только через защищённую цепь питания после испытаний |
| 6 / 14 | CAR-CAN | В выбранной версии не подключаются |

Номера у штекера и розетки зеркально воспринимаются при взгляде с разных сторон. Опирайся на отлитые номера контактов и прозвонку. В EV-CAN ожидаются кадры `0x1DB`, `0x55B`, `0x390` на 500 кбит/с. Если `0x390` отсутствует, текущая версия оставляет зарядный статус неизвестным; требуется исследовать расположение PDM-сигнала у этого исполнения. Шины между собой не соединяются.

## Постоянное питание

| Этап | Соединение |
|---|---|
| Вход | OBD16 → предохранитель |
| Защита аккумулятора | Предохранитель → аппаратная отсечка низкого напряжения |
| Преобразование | Отсечка → автомобильный защищённый DC-DC |
| ESP | Выход 5 В DC-DC → штатный вход питания DevKit |
| Возврат | Общая земля по сервисной схеме → GND DC-DC и DevKit |

Простой открытый LM2596 без автомобильной защиты предназначен для стенда. При одновременном USB и внешнем 5 В нужно учитывать схему развязки самой платы и предотвращать обратное питание USB. К высоковольтным проводам и разъёмам батареи устройство не подключается.

Перед постоянной установкой измерь фактический ток покоя ESP, CAN-модуля и телефона. Испытай ночной простой и работу аппаратной отсечки. Наличие защиты по напряжению не заменяет измерение потребления. Silent защищает от передачи команд; короткое замыкание, ошибка монтажа или повреждённый трансивер могут влиять на шину.

## GNSS

| GNSS | ESP |
|---|---|
| TX с логикой 3,3 В | GPIO16 |
| GND | GND |
| VCC | Напряжение по спецификации конкретного модуля |

UART: 9600 бод. Включи `ENABLE_GPS=1`, установи TinyGPSPlus. Сигнальные GPIO ESP рассчитаны на 3,3 В. GPS телефона через Hotspot автоматически не передаётся.
