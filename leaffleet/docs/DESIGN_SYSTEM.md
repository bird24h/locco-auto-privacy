# LeafFleet — візуальна система 1.0.6

Референс: наданий користувачем відеозапис темного інтерфейсу Uklon. Перенесено відчуття простору, об’єктну 3D-графіку, перекриття панелей, стримані поверхні та характер руху. Композиція відповідає телеметрії одного Leaf.

## Композиція

Головний екран починається зі сцени автомобіля: SOC є головним числом, автомобіль має власний простір та м’яке освітлення. Панель показників перекриває нижній край сцени. Об’ємні об’єкти ведуть до зарядок, поїздок і стану. Зелена панель цілі відкриває налаштування. Графік та події використовують підняті картки. Технічні параметри розкриваються окремо.

Картки: 26–34 px; кнопки: 14–16 px. Тіні залежать від рівня поверхні. Тонка верхня грань відокремлює панелі від фону. Системний шрифт, табличні цифри й одна система SVG-іконок використовуються на всіх екранах.

## Графіка та рух

`cloud/public/assets/ev-objects.png` — оригінальна 3D-графіка, створена imagegen для цього інтерфейсу. Прозорий атлас містить умовний електромобіль, станцію, карту та батарею. Зображення автомобіля є умовною 3D-ілюстрацією. В атласі ліві об’єкти займають 62,5% ширини, праві — 37,5%; два ряди однакової висоти. Атлас відображається через CSS.

Входи екранів: 280 мс; висувна панель: 350 мс; кнопки зменшуються під час натискання. У режимі зменшеного руху анімації вимкнені. Перемикання теми зберігається в поточній вкладці. Нативний `dialog` забезпечує фокус, Escape та модальність; натискання за межами вмісту закриває панель.

## Поведінка

Чотири основні розділи: Авто, Історія, Стан, Налаштування. Історія має три підрозділи. Швидкі дії використовують ті самі маршрути. Демо відкривається через окрему панель; початок відтворення закриває її. Потужність приховується при застарілих вимірюваннях; останній SOC залишається з часовою позначкою. Пропуски вимірювань розривають лінію й заливку графіка.

Канонічні стилі: `cloud/public/theme.css`. Збірка `npm run demo:build` вбудовує стилі, контролер, сценарій та PNG в один автономний HTML. Рендеринг у реальному браузері й на iPhone залишається відкритим пунктом приймки.

## Текст інтерфейсу

Короткі функціональні назви. Слогани, декоративні надзаголовки, повтори й довгі пояснювальні абзаци прибрані. Інструкції доступні в документації. Позначення демо, втрати зв’язку, актуальності даних і потреби в GNSS залишені.
